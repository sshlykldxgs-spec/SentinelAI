# 评委演示脚本（约 3 分钟）

## 0:00–0:35 总览

打开工作台，说明 SentinelAI 是供应链证据驱动的决策辅助系统。展示 6 家供应商、2 家触发演示风险阈值、风险矩阵与数据来源。所有数字来自 suppliers.csv；单期快照不伪造收益或趋势。Demo 是规则演示，Live 需模型配置，Replay 是离线回放。

## 0:35–1:20 五阶段协作

选中 suppliers.csv 与 brief.txt，启动 Demo。查看 Planner 验收条件、Research 文件证据、Analyst Python 指标、Risk 独立审查、Action 建议。打开 Agent 详情展示实际耗时、模型/规则标识、输入/输出、证据数和真实工具事件。任务完成后 Action 待审批，不等于执行采购。

## 1:20–2:00 证据与报告

打开证据中心，搜索 Meridian，按供应商/文件/风险筛选，指出 record:2 的来源。Python 计算 M-* 与模型假设分开。报告展示风险排序、审查意见、引用覆盖口径和未解决问题；下载 Markdown 与当前报告内容一致。

## 2:00–2:35 人工审批

打开待审批，查看负责人、期限、影响范围和 Reviewer 意见。填写意见并批准/驳回/要求补充资料。审批由后端校验本机会话和状态。证据不足不能批准；补充资料需要重新分析。批准不执行采购、付款、合同或网络操作。

## 2:35–3:00 可观测性与真实模式

历史保留进程内事件。配置页显示服务端模型状态与预算。没有凭据时 Live 不可进入；配置完成后可主动测试并运行 Live。Replay 可验证链路但不是在线推理。现场展示真实模式前需单独完成 docs/MODEL_SETUP.md 在线验收。

失败演示可使用离线测试展示 timeout/auth/5xx/结构校验与拒绝审批路径；不要人为伪造故障为在线模型结果。网络断开后 SSE 会补发事件，浏览器不自行宣告任务成功。
